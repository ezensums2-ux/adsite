HTML 문서는 어떤 구조를 가질까요?

HTML 문서는 기본적으로 아래처럼 구성됩니다. 각 태그는 문서의 역할을 나누고, 브라우저는 이 구조를 보고 화면에 표시합니다.

<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <title>나의 첫 HTML</title>
  </head>
  <body>
    <h1>안녕하세요!</h1>
    <p>HTML 공부를 시작합니다.</p>
  </body>
</html>
<!DOCTYPE html>

현재 문서가 HTML5 문서라는 것을 브라우저에 알려줍니다.

<html>

HTML 문서 전체를 감싸는 가장 바깥쪽 태그입니다.

<head>

화면에는 보이지 않지만 문서 정보를 담는 공간입니다.

<meta charset="UTF-8">

한글과 같은 문자를 올바르게 표시하도록 문자 인코딩을 지정합니다.

<title>

브라우저 탭에 보이는 문서 제목을 설정합니다.

<body>

실제로 사용자에게 보이는 내용이 들어가는 영역입니다.

오늘 기억할 것

  • HTML 문서는 일정한 기본 구조를 가집니다.
  • head에는 문서 정보가 들어갑니다.
  • body에는 화면에 보이는 내용이 들어갑니다.
  • title은 브라우저 탭 제목을 의미합니다.

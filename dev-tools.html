자주 쓰는 계산 도구

값을 바꾸면 결과와 복사할 코드가 바로 업데이트됩니다.

PX → REM 변환기

기준 글자 크기를 바꾸어도 rem 값이 즉시 다시 계산돼요.

2rem

REM → PX 변환기

1rem은 기본 글자 크기만큼의 크기를 의미합니다.

32px

CSS Clamp 생성기

Preferred 값은 뷰포트 기준으로 변환합니다. 1200px 화면에서 24px은 2vw예요.

font-size: clamp(16px, 2vw, 40px);

Aspect Ratio 계산기

가로와 세로의 최대공약수로 가장 간단한 비율을 구합니다.

16 : 9

URL Encode / Decode

URL에 넣을 텍스트를 인코딩하거나 percent 인코딩된 문자열을 디코딩합니다.

Base64 변환

한글을 포함한 UTF-8 텍스트를 Base64로 인코딩하거나 다시 디코딩합니다.

JSON Formatter

JSON 문법을 검사하고 읽기 쉬운 형태 또는 압축된 형태로 정리합니다.

Lorem Ipsum 생성기

필요한 문장 수만큼 반복 가능한 임시 문구를 생성합니다.

CSS Minify

CSS의 주석과 불필요한 공백을 제거합니다. 문자열과 URL 내부의 내용은 유지합니다.

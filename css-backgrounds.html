배경과 이미지에 자주 쓰는 속성

background-color는 배경색을 지정하고, background-image는 이미지나 그라데이션을 배경으로 표시합니다. 이미지 배경은 background-size, background-position, background-repeat으로 배치할 수 있습니다. 콘텐츠 이미지에는 object-fit을 사용합니다.

background-image

이미지 주소나 linear-gradient, radial-gradient를 배경으로 표시합니다.

background-size

cover는 빈틈없이 채우고, contain은 이미지 전체가 보이도록 맞춥니다.

background-position

상자 안에서 배경 이미지가 놓일 위치를 정합니다.

object-fit

<img> 같은 콘텐츠 이미지를 정해진 상자에 맞추는 방법입니다.

기억해 두세요

  • 단색 배경은 background-color, 그라데이션이나 배경 그림은 background-image로 지정합니다.
  • cover는 영역을 채우고, contain은 이미지 전체가 보이도록 합니다.
  • object-fit은 이미지 요소 자체가 상자 안에 맞춰지는 방식을 정합니다.

개념 설명

폼과 버튼은 어떤 역할을 할까요?

폼은 사용자가 정보를 입력하는 공간을 만들고, 버튼은 전송이나 확인 같은 동작을 실행합니다. 실제로는 여러 입력 요소가 함께 사용됩니다.

<form>
  <label for="name">이름</label>
  <input id="name" type="text" placeholder="이름을 입력하세요">
  <button type="submit">전송</button>
</form>
form

사용자의 입력을 받아 서버나 처리 코드로 전달하는 영역을 만듭니다.

input

텍스트, 비밀번호, 체크박스, 라디오 같은 다양한 입력 필드를 만듭니다.

label

입력 요소를 설명하고, 화면 낭독기와 키보드 사용자에게 더 좋은 접근성을 제공합니다.

button

클릭으로 어떤 동작을 실행할지 정하는 요소입니다. submit, reset, click 같은 역할을 가집니다.

textarea

여러 줄 문장을 입력할 때 사용합니다. 메모나 의견 입력에 적합합니다.

select

여러 선택지 중 하나를 고르도록 하는 드롭다운 형태입니다.

오늘 기억할 것

  • form은 입력을 묶어 전달하는 영역입니다.
  • label은 입력 내용을 설명해 줍니다.
  • input과 textarea는 사용자 입력을 받습니다.
  • button은 사용자가 선택한 행동을 실행하게 합니다.

QUICK NOTE

box-shadow 읽기

box-shadow: 가로 세로 흐림 퍼짐 색상; 순서로 값을 적어요. inset은 그림자를 안쪽으로 넣습니다.

흐림은 가장자리의 부드러운 정도, 퍼짐은 그림자 모양 자체의 크기예요. 음수 퍼짐은 그림자를 줄입니다.

직접 해보기흐림을 0으로 두고 퍼짐만 바꿔 비교해보세요.

QUICK NOTE

border-radius 이해하기

border-radius는 요소의 모서리를 둥글게 만들어요. 하나의 값은 네 모서리에 모두 적용되고, 네 값을 쓰면 왼쪽 위부터 시계 방향으로 각각 지정합니다.

값을 크게 만들수록 둥글어집니다. 네 모서리 값이 충분히 크면 알약 모양의 캡슐 형태가 돼요.

직접 해보기함께 조절을 끄고 왼쪽 위 모서리만 크게 바꿔보세요.

QUICK NOTE

border 속성 이해하기

border는 두께, 선 모양, 색상 순서로 값을 지정해요. 예를 들어 2px dashed #6546c8은 보라색 점선 테두리입니다.

네 면을 모두 선택하면 짧은 border 선언을 만들고, 일부 면만 선택하면 해당 면별 속성을 생성합니다. 두께를 0으로 하거나 선 모양을 없음으로 바꾸면 테두리가 사라져요.

직접 해보기위쪽과 아래쪽만 선택하고 점선 효과를 비교해보세요.

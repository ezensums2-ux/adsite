JavaScript 소개

JavaScript는 웹 페이지에 동작을 더하는 언어입니다. HTML 요소를 선택하고 이벤트를 연결해 화면을 바꿀 수 있어요.

const title = document.querySelector('h1');

변수와 자료형

다시 대입하지 않을 값은 const, 바뀔 값은 let으로 선언합니다.

const name = '민지';
let score = 10;

연산자

산술, 비교, 논리 연산자로 값을 계산하고 조건을 만들어요.

const total = 10 + 5;
const passed = total >= 10;

조건문

조건이 참인지에 따라 다른 코드를 실행합니다.

if (score >= 60) {
message = '합격';
}

반복문

배열의 항목처럼 반복할 일을 for 문으로 처리할 수 있어요.

for (let i = 0; i < 3; i++) {
console.log(i);
}

함수

여러 번 사용할 동작에 이름을 붙여 재사용합니다.

function greet(name) {
return `안녕, ${name}`;
}

배열

순서가 있는 여러 값을 하나로 묶습니다.

const colors = ['보라', '파랑'];
colors[0];

객체

이름이 있는 속성으로 관련된 데이터를 묶습니다.

const button = {
text: '저장',
disabled: false
};

DOM 선택

querySelector로 CSS 선택자를 사용해 첫 요소를 찾습니다.

const preview = document.querySelector('#preview');

이벤트

사용자의 클릭에 반응하도록 click 이벤트를 연결합니다.

button.addEventListener('click', () => {
preview.textContent = '클릭했어요';
});

HTML / CSS 변경

textContent와 style 속성으로 화면의 내용과 모양을 바꿉니다.

preview.textContent = '새 내용';
preview.style.color = 'purple';

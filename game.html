🎮 게임 조작 방법

다양한 입력 장치로 손쉽게 플레이할 수 있습니다:

  • 키보드 조작: 방향키(↑, ↓, ←, →) 또는 W, A, S, D 키를 눌러 상하좌우로 이동합니다.
  • 모바일 터치 스와이프: 화면을 위/아래/좌/우로 가볍게 밀거나, 화면을 탭하면 앞으로 전진합니다.
  • 온스크린 가상 패드: 화면 우측 하단의 방향 버튼(▲, ▼, ◀, ▶)을 터치하거나 클릭하여 이동할 수 있습니다.
  • 나무 장애물: 잔디밭의 나무가 있는 칸은 지나갈 수 없으니 우회해서 건너야 합니다.

⚙️ Three.js 기술 원리 분석

CodePen 원작의 핵심 3D 그래픽 기법들을 분석하여 구현했습니다:

  • 직교 투영 카메라 (OrthographicCamera): 원근 왜곡을 없애고 쿼터뷰 각도(-140, -320, 310)를 설정해 복셀 특유의 정갈한 아이소메트릭 시점을 연출합니다.
  • 절차적 무한 맵 생성 (Procedural Lanes): 플레이어 전진 시 잔디(Forest), 승용차 도로(Car), 트럭 도로(Truck)를 동적으로 이어 붙이고 지나간 레인은 메모리에서 해제합니다.
  • AABB 충돌 판정 & Squish 연출: 차량의 가로/세로 바운딩 박스와 플레이어 위치를 매 프레임 계산해 충돌 시 닭이 납작해지는 애니메이션 효과를 부여합니다.
  • Web Audio API 사운드: 외부 음원 로딩 없이 자바스크립트 신디사이저로 점프, 충돌, 신기록 효과음을 즉시 생성합니다.

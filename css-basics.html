개념 설명

CSS를 HTML에 연결하는 세 가지 방법

인라인 방식은 요소에 직접 쓰고, 내부 방식은 HTML의 <style> 안에 작성합니다. 외부 방식은 별도의 CSS 파일을 만들고 <link>로 연결하며, 여러 페이지에서 재사용하기 좋아 가장 널리 사용됩니다.

인라인 CSS

HTML 요소의 style 속성에 직접 작성합니다.

<p style="color: purple;">
  안녕하세요
</p>

내부 CSS

HTML 문서의 <head> 안에 <style>을 작성합니다.

<style>
  p { color: purple; }
</style>

외부 CSS

별도 파일을 <link> 태그로 연결합니다.

<link rel="stylesheet"
  href="style.css">
선택자

선택자는 스타일을 적용할 대상을 고릅니다

태그 선택자 · p

같은 태그를 모두 선택합니다. 예: p

클래스 선택자 · .notice

같은 class 이름을 가진 요소를 선택합니다. 예: .notice

아이디 선택자 · #message

특정 id를 가진 요소를 선택합니다. 예: #message

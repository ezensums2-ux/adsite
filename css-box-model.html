개념 설명

요소의 상자는 네 부분으로 이루어져요

안쪽부터 콘텐츠(content), 안쪽 여백(padding), 테두리(border), 바깥 여백(margin) 순서입니다. 패딩은 콘텐츠와 테두리 사이를 넓히고, 마진은 다른 요소와의 바깥 간격을 만듭니다.

margin · 바깥 여백
border · 테두리
padding · 안쪽 여백
content · 콘텐츠
content

텍스트나 이미지처럼 실제 내용이 놓이는 영역입니다.

padding

콘텐츠와 테두리 사이의 안쪽 여백입니다.

border

패딩과 콘텐츠를 둘러싸는 테두리입니다.

margin

테두리 바깥쪽에서 주변 요소와의 간격을 만듭니다.

크기 계산

box-sizing에 따라 width의 의미가 달라져요

content-box에서는 width에 콘텐츠 크기만 포함되어 패딩과 테두리가 바깥으로 더해집니다. border-box에서는 width 안에 콘텐츠·패딩·테두리가 모두 포함되어 상자의 전체 너비를 맞추기 쉽습니다.

/* 콘텐츠 너비가 200px이고 padding 20px, border 4px인 경우 */
content-box: 전체 너비 = 200 + 40 + 8 = 248px
border-box:  전체 너비 = 200px

정리

기억해 두세요

  • 박스 모델은 콘텐츠, 패딩, 테두리, 마진으로 구성됩니다.
  • 패딩은 테두리 안쪽 공간, 마진은 테두리 바깥쪽 공간입니다.
  • border-box는 지정한 width에 패딩과 테두리를 포함합니다.

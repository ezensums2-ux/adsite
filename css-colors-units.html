색상 표현

같은 색도 여러 방식으로 쓸 수 있어요

CSS 색상은 색상 이름, HEX, RGB, HSL 등으로 표현할 수 있습니다. 색상 선택기로 한 가지 색을 정한 다음 표기 방식을 바꾸어 코드가 어떻게 달라지는지 확인해 보세요.

HEX

#6546c8처럼 16진수로 색을 나타냅니다.

RGB

rgb(101, 70, 200)처럼 빨강·초록·파랑의 양으로 나타냅니다.

HSL

색상(Hue), 채도(Saturation), 명도(Lightness)로 색을 나타냅니다.

크기 단위

단위마다 기준이 달라요

px

고정된 픽셀 단위입니다. 예: 24px

rem

문서 최상위 요소(html)의 글자 크기를 기준으로 합니다. 보통 기본값은 16px입니다.

em

해당 요소의 부모 글자 크기를 기준으로 계산합니다.

%

속성이 적용되는 대상의 기준 크기에 대한 비율입니다. 이 실습의 글자 크기는 부모 글자 크기를 기준으로 합니다.

vw

화면 너비(viewport width)의 1%를 기준으로 합니다.

vh

화면 높이(viewport height)의 1%를 기준으로 합니다.

정리

기억해 두세요

  • HEX, RGB, HSL은 CSS 색상을 서로 다른 방식으로 표현합니다.
  • px는 고정 크기이고, rem과 em은 글자 크기를 기준으로 계산합니다.
  • %, vw, vh는 각각 대상이나 화면 크기를 기준으로 달라집니다.

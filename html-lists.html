목록과 표

목록은 항목을 나열하고, 표는 정보를 구조적으로 정리해 보여 줍니다. 같은 내용을 다르게 표현하면 읽는 사람이 훨씬 이해하기 쉬워져요.

개념 설명

목록과 표는 정보를 어떻게 정리할까요?

목록은 순서가 있거나 없는 항목을 보여 주고, 표는 행과 열을 이용해 정보를 정리합니다. 태그를 잘 쓰면 내용을 더 쉽고 빠르게 이해할 수 있어요.

  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<table>
  <tr>
    <th>과목</th>
    <th>설명</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>구조를 만듭니다.</td>
  </tr>
</table>
ul

순서가 없는 목록을 표현합니다. 항목들이 같은 중요도를 가질 때 자주 사용합니다.

ol

순서가 있는 목록을 표현합니다. 절차, 순서, 우선순위가 중요할 때 적합합니다.

li

목록의 각 항목을 의미합니다. ul 또는 ol 안에 들어갑니다.

table

행과 열로 정보를 정리하는 표 구조를 만듭니다. 세부 정보를 비교하기에 좋습니다.

th

표의 제목 칼럼 또는 행을 나타냅니다. 보통 맨 위 또는 첫 열에 사용됩니다.

td

표의 실제 데이터가 들어가는 칸입니다. 행과 열의 내용을 담습니다.

학습 포인트

오늘 기억할 것

  • ul은 순서가 없는 목록, ol은 순서가 있는 목록입니다.
  • li는 각 항목을 나타냅니다.
  • table은 여러 정보를 행과 열로 정리할 때 사용합니다.
  • th는 표의 제목, td는 실제 데이터입니다.

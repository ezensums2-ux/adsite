핵심 개념

시작 상태와 끝 상태 사이의 변화를 보간해요

transition은 사용자의 입력 등으로 CSS 값이 바뀔 때 두 상태 사이를 부드럽게 연결합니다. 애니메이션 대상 속성, 지속 시간, 속도 곡선, 지연 시간을 설정합니다.

property변화시킬 CSS 속성을 고릅니다.
duration · delay변화에 걸리는 시간과 시작 전 대기 시간입니다.
timing-function시간에 따른 변화 속도 곡선을 정합니다.

개념 설명

같은 속성이라면 어떤 규칙이 우선일까요?

CSS는 여러 선택자가 같은 속성을 정할 때 점수를 비교해서 가장 높은 우선순위를 가진 규칙을 적용합니다. 일반적으로 태그 선택자는 가장 낮고, 클래스 선택자는 더 높으며, 아이디 선택자는 가장 높습니다.

p { color: green; }
.feature { color: purple; }
#hero { color: orange; }
태그 선택자

예: p · 가장 기본이지만 우선순위가 낮습니다.

클래스 선택자

예: .feature · 태그보다 더 구체적이라 우선순위가 올라갑니다.

아이디 선택자

예: #hero · 같은 속성이라면 가장 높은 우선순위를 가집니다.

상속

부모의 color 같은 값은 자식 요소에게 전달될 수 있습니다. 이를 상속이라고 합니다.

정리

한 줄 정리

  • 같은 속성이라면 브라우저는 선택자의 점수를 비교해서 더 높은 규칙을 적용합니다.
  • 기본적으로 태그 < 클래스 < 아이디 순서로 우선순위가 올라갑니다.
  • 부모의 color 값은 자식에게 전달될 수 있고, inherit를 사용하면 명시적으로 상속을 적용할 수 있습니다.

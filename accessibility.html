웹 접근성

누구나 다양한 기기와 방법으로 웹 콘텐츠를 이용할 수 있도록 만드는 기본을 배웁니다.

웹 접근성이란?

웹 접근성은 장애 여부나 사용 환경과 관계없이 정보와 기능에 접근할 수 있도록 하는 것입니다. 올바른 HTML 요소를 쓰는 것이 가장 좋은 출발점이에요.

색상 대비 계산기

WCAG 기준으로 일반 텍스트 4.5:1, 큰 텍스트 3:1 이상을 권장합니다.

대비 미리보기 문장
Contrast Ratio 2.32 : 1

이미지 alt

잘못된 예

이미지의 정보를 대체 텍스트 없이 제공합니다.

<img src="chart.png">
올바른 예

정보를 전달하는 이미지에는 의미를 설명하는 대체 텍스트를 씁니다.

<img src="chart.png" alt="월별 매출 그래프">

Label과 Input

잘못된 예

<input placeholder="이름"> placeholder만으로 입력 목적을 설명하지 마세요.

올바른 예

키보드 접근성

Tab으로 이동하고 Enter 또는 Space로 실행할 수 있도록 네이티브 링크와 버튼을 우선 사용합니다.

Focus

현재 키보드 위치를 나타내는 포커스 표시를 제거하지 말고 충분히 눈에 띄게 유지합니다. 위 버튼에 Tab 키로 이동해 보세요.

Heading 구조

페이지 제목은 h1, 하위 주제는 h2, 세부 주제는 h3 순서로 계층을 표현합니다. 글자 크기만을 위해 제목 단계를 건너뛰지 마세요.

ARIA 기초

기본 HTML 의미가 부족할 때 aria-label, aria-expanded, aria-live 등으로 이름과 상태를 보완합니다. ARIA는 잘못된 HTML 요소를 대신하지 않습니다.

접근성 체크리스트

  • 이미지에 목적에 맞는 alt가 있는가?
  • 키보드만으로 모든 기능을 사용할 수 있는가?
  • 포커스 위치가 분명하게 보이는가?
  • 텍스트와 배경의 대비가 충분한가?
  • 제목과 폼 레이블이 올바르게 연결됐는가?
